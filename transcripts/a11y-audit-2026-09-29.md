## Residual `incomplete` results and why they are acceptable

`axe-core` reports `incomplete` when it cannot decide automatically. Each remaining case was
reviewed by hand:

- **Text over gradients** (`.login-left` sign-in story, `.overview-banner` copy): axe cannot
  determine the backdrop for a gradient. Computed contrast of the text colors (`#ffffff`,
  `#a8bfaa`, `#dfe9df`, `#b5c6b4`, `#f4f7f0`, `#b5c4b7`, `--lime #c8ef73`) against every gradient
  endpoint (`#2b4435`/`#1b2b23`/`#122019` and `#314d3c`/`#1d3227`/`#192a21`/`#20382b`) is
  **5.1:1 or better**; the lightest gradient stop is the worst case, so the whole ramp passes 4.5:1.
- **Short numeric labels** (`.filter-active > b`, chart captions, small counts): axe skips text it
  considers too short to identify. These use palette values that were re-derived in this session to
  reach 4.5:1 against their measured backgrounds.
- **Decorative glyphs** (`.star-one`, `.star-two`): pure decoration inside a container that is
  already `aria-hidden="true"`, so they are not exposed to assistive technology.

## Violations found and fixed in this session

| Rule | Impact | Where | Fix |
|---|---|---|---|
| `color-contrast` | serious | 194 text nodes across the sign-in screen, sidebar group labels, breadcrumbs, table headers, audit rows, status pills, queue items, rubric chips | Re-derived 67 palette values to meet 4.5:1 against their real backgrounds (darkened muted greens/grays, lightened the dark-sidebar label); visual language preserved |
| `empty-table-header` | minor | Two action columns (`campaigns` and `submissions` tables) used `<th />` | Added a visually hidden `Actions` label plus the `.visually-hidden` utility |
| `landmark-unique` | moderate | Three `<aside>` landmarks had no accessible names | Added `aria-label` to the workspace sidebar, blind-review queue, and adjudication queue |
| `aria-prohibited-attr` | serious | `aria-label` on plain `<div>` containers (`.demo-users`, `.workspace-switcher`, `.bar-chart`) | Paired each with `role="group"` so the accessible name is exposed |

## Reproduce

```bash

bun install && bash setup.sh --seed && bun start
# 2. From a scratch directory with puppeteer-core + axe-core + a Chromium build:
node audit.mjs   # audits 10 surfaces and writes a JSON report
```

Raw axe results for every surface, including per-node failure summaries, are in
`transcripts/a11y-audit-report.json`.
